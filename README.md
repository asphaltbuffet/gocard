# gocard

> A Go library for representing and manipulating playing cards and decks.

## Installation

```bash
go install github.com/asphaltbuffet/gocard@latest
```

Or with Nix:

```nix
# flake.nix input
gocard.url = "github:asphaltbuffet/gocard";
```
